# Saunet Samurai

A Java 2D platform game with animated samurai combat, two tile-based levels, scrolling backgrounds, enemies, music, and sound effects. Built with Java AWT/Swing and the included `game2D` framework.

## Requirements

- JDK 17 or newer, with `java` and `javac` available in your terminal.
- A desktop environment to display the game window.

No external libraries or build tools are required.

## How to run the game

### In VS Code on Windows

1. Open the project folder in VS Code.
2. Select **Terminal > New Terminal** and use PowerShell.
3. Make sure the terminal is in the project root, which contains `src`, `images`, `maps`, and `sounds`. For the current local folder, run:

   ```powershell
   cd "C:\Users\neilc\VS Code\2-D game"
   ```

   If you downloaded the project elsewhere, use that folder's path instead.

4. Compile the game:

   ```powershell
   javac -d bin src/game2D/*.java src/Game.java
   ```

5. Start the game:

   ```powershell
   java -cp bin Game
   ```

A separate game window opens. Click it to focus the controls, then use the arrow keys to move and jump. Press Escape to quit.

### From a fresh GitHub clone

With Git and a JDK installed, run:

```powershell
git clone https://github.com/saunetgrey/2-D-game.git
cd 2-D-game
javac -d bin src/game2D/*.java src/Game.java
java -cp bin Game
```

Recompile after changing Java source. The `bin` folder is generated by compilation and is not included in the repository.

### Troubleshooting

- **`java` or `javac` is not recognized:** install JDK 17 or newer, add its `bin` folder to your PATH, and reopen the terminal. Check with `java -version` and `javac -version`.
- **Could not find or load main class Game:** run the compile command successfully before launching, and check that your terminal is in the project root.
- **Missing images, maps, or sounds:** launch from the project root, not from `src` or `bin`.

With Java support installed in VS Code, you can also open `src/Game.java` and click **Run** above `main`. Keep the working directory set to the project root.

## Controls

| Key | Action |
| --- | --- |
| Left / Right arrow | Walk left / right |
| Up arrow | Jump |
| Space | Run right (release the arrow keys) |
| X / C / Z | Different sword attacks |
| B | Toggle collision debugging |
| R | Restart after completing the game |
| Escape | Quit |
| Mouse press | Play taunt sound |

Move through both levels to complete the game.

## Project layout

- `src/Game.java`: entry point, game rules, controls, and level setup.
- `src/game2D/`: game loop, animation, sprites, tile maps, and audio support.
- `images/`: character sprites and backgrounds.
- `maps/`: level layouts and tile images.
- `sounds/`: music and sound effects.
- `bin/`: generated classes; recreated by compilation and ignored by Git.

The Eclipse project configuration is included. `.gitignore` excludes compiled output, JVM crash logs, and operating-system metadata.
